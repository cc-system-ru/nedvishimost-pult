# Пульт агентства «Рубан Недвижимость»

Пульт управления агентством недвижимости для собственника, РОПов и агентов: деньги и P&L, воронка сделок, контроль регламента, баллы ЕКА, эксклюзивы, планёрки и разборы от ИИ.

> **Важно.** Текущая версия (`index.html`) — прототип, работающий **внутри Claude** (артефакт claude.ai).
> База данных, вход сотрудников и ИИ предоставляются платформой Claude через `window.claude.use(...)`.
> Если открыть файл вне Claude (GitHub Pages, локально), пульт покажет «База недоступна».
> Перенос на свой сервер и интеграция с Битрикс24 / amoCRM описаны в [docs/tz-migration.md](docs/tz-migration.md).

Репозиторий должен быть **приватным**: в коде — скрипты продаж и регламенты агентства.

## Что внутри

| Раздел | Для кого | Что делает |
|---|---|---|
| Собственник | владелец | Получено / маржа / деньги в пути, план от желаемого дохода (сверху вниз и снизу вверх), управленческий P&L (кассовый и по закрытым сделкам), прогноз денег на 3 месяца, расходы по статьям, окупаемость источников, экономика агентов, ипотека по банкам, оценка и ИИ-разбор РОПов |
| РОП: контроль | РОП своего офиса | Повестки планёрок от ИИ, «что сделать РОПу сейчас», нарушения SLA, обзвон после показа, рейтинг ЕКА и лиды на завтра, подтверждение отчётов, распределение лидов, выборочная проверка CRM, аудит звонков, найм, стажёры, привязка аккаунтов |
| Воронка | все | Этапы как в ТЗ Битрикс24 + «Ипотека на одобрении», карточка сделки с БАНТ, задачами, 26 точками касания, касаниями после сделки, ИИ-подсказками |
| Эксклюзивы | все | Чек-лист на 3 месяца по регламенту, подбор покупателей из воронки |
| Мой день | агент | Баллы и зона, лиды на завтра, % плана и run rate, задачи, ежедневный отчёт |
| ИИ-инструменты | все | Разбор звонка, отработка возражений, отказ по ипотеке, 15 скриптов агентства, вопросы к данным |

Фильтры: офис и период (день, неделя, 2 недели, месяц, квартал).

## Роли

| Роль | Как определяется сейчас (Claude) | Видит |
|---|---|---|
| Собственник | владелец артефакта (`user.isOwner()`) | всё, может «смотреть как» РОП/агент |
| РОП | доступ «Редактор» (`user.canEdit()`), офис выбирается при первом входе | свой офис, без финансов собственника |
| Агент | доступ «Участник», аккаунт привязан к карточке агента (запрос → подтверждение РОПа) | только свои сделки, эксклюзивы, отчёт |

## Структура

```
index.html            весь пульт: разметка, стили, логика (один файл, без сборки)
docs/architecture.md  модель данных, правила доступа, бизнес-правила и формулы
docs/tz-migration.md  ТЗ на перенос на свой сервер и интеграцию с Битрикс24 / amoCRM
```

Внешние зависимости: шрифты Google Fonts, SheetJS (`xlsx@0.18.5`, cdnjs) — загружается только при выгрузке в Excel.

## Как запустить сейчас

Пульт опубликован как артефакт claude.ai с возможностями `db` (с правилами доступа из `docs/architecture.md`), `user` (scope `profile`), `sample` (ИИ), `downloads` (Excel). Для работы все сотрудники должны быть участниками организации в Claude.

## Порядок развития

1. Пилот в одном офисе в Claude (2 недели), импорт сделок из выгрузки CRM.
2. Перенос на сервер в РФ и приложение Битрикс24 по `docs/tz-migration.md`.
